Comment lire ces démos

Chaque maquette est en stricte continuité du document AX5-CitaFlow_Personas_Complets_v1 qui consolide 26 personas issus de l'écosystème urbain montréalais. Le format de chaque démo s'adapte au canal natif du persona : dashboard web pour les coordonnateurs, mobile iPhone pour les inspecteurs, carte ops pour les opérateurs de flotte, Waze native pour les automobilistes, portail conformité pour les maîtres d'œuvre.

Données
Données réalistes basées sur les sources réelles du projet (CNESST 54 k lésions, SAAQ 8 k accidents zones travaux, GBFS BIXI live, Waze CCP partenaire ville).
Workflows
Numérotation référencée (#1-102) pointant vers la matrice 100+ workflows opérationnels documentée dans les fichiers projet.
Métriques
ROI affichés issus du document personas v1, vérifiables et défendables devant un jury IVÉO ou un partenaire institutionnel.
